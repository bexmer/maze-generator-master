Maze Generator

Create, solve and download random maze puzzles in any size or color with this online tool. Enter the values for your maze design below and click the "Generate Maze" button.

The generator now supports multiple algorithms. By default it uses the classic randomized Prim's method, and you can switch back to recursive backtracking if you prefer. For more information check out the Github Repository.
